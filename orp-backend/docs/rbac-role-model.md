# 角色与权限说明

平台使用 RBAC：一个用户可以绑定多个角色，用户最终权限为所有已启用角色权限的并集；每项权限只在授予它的角色中心范围内生效。权限检查由后端执行，前端同时依据有效权限控制菜单、路由和操作按钮可见性。

## 内置角色

| 角色 | 职责 | 权限范围 |
| --- | --- | --- |
| 超级管理员 | 管理账号、角色和平台全部能力 | `*`；仅此角色可访问用户与角色管理，固定内置，不可编辑或删除 |
| 平台管理员 | 日常平台运维 | 查看配置、编辑配置、执行发布、节点运维、系统运维、查看审计；不管理账号和角色 |
| 配置编辑员 | 维护中心、节点和代理配置 | 查看配置、编辑配置；不能发布或执行节点运维 |
| 发布操作员 | 预检并发布配置 | 查看配置、发布、分批推进、中止和回滚 |
| 审计只读 | 查询配置和审计信息 | 查看配置、查看审计；不能写入 |
| 敏感数据审计员 | 有需要时查看敏感配置 | 查看配置、查看审计、读取证书私钥和敏感配置明文 |

内置角色的权限固定。若需要不同权限组合或中心范围，请创建自定义角色并配置权限和中心范围。

## 权限项

| 权限标识 | 作用 |
| --- | --- |
| `orp:read` | 读取平台配置和运行信息 |
| `orp:config:write` | 创建、修改和删除配置资源 |
| `orp:publish` | 执行发布预检、发布、分批推进、中止和回滚 |
| `orp:node:operate` | 修改节点运行状态、登记 Agent 证书和触发重载 |
| `orp:system:manage` | 管理告警通道、TLS 告警规则和 GeoIP 数据库 |
| `orp:audit:read` | 读取审计日志 |
| `orp:secrets:read` | 读取证书私钥和敏感配置明文 |

自定义角色不能分配未知权限标识或 `*`。旧权限 `orp:write` 在运行时兼容映射为 `orp:config:write`，不会自动获得发布或运维能力。

## 中心范围

每个角色都可配置中心范围：选择 `全部中心` 会保留全局访问；选择一个或多个中心时，用户只能读取或变更这些中心及其节点和代理资源。多个角色的权限与范围按同一角色配对判定，再对允许结果取并集，避免一个角色的宽范围扩大另一个角色的写权限。中心列表、直接资源读写删除、旧版中心接口、发布节点、日志和审计记录均由后端执行范围校验。全局配置项由具备相应权限的角色共享读取和维护。

中心范围不替代权限项：例如只读角色即使被授予某中心，也不能修改该中心资源。敏感明文仍要求 `orp:secrets:read`。

为兼容升级前的角色，迁移会把既有角色范围设为全部中心；创建的新自定义角色默认没有中心资源范围。管理员可在角色编辑中按最小范围调整既有角色。

账号、角色、角色权限和密码重置变更会与审计记录在同一事务提交；审计快照不包含密码或密码哈希。至少保留一个启用的超级管理员账号，不能通过用户编辑禁用或降级最后一个超级管理员。

## 当前边界

权限目录按平台配置、发布、节点运维、系统运维、审计、敏感数据及账号角色管理分层展示。仅超级管理员可管理账号、角色和权限目录。角色和用户列表支持关键字/状态筛选，用户关键字覆盖用户名、姓名、邮箱和手机号。角色支持按中心隔离配置资源和节点运维数据；平台内置角色默认覆盖全部中心。自定义角色的中心范围默认空，需要显式配置。发布操作不要求独立人工审批；服务端仍会校验调用者权限及现有发布状态规则。
