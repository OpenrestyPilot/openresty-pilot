# ORP 后端 UI 验收

该验收通过浏览器真实访问当前运行的 Vite 页面，再由页面请求 Go 控制面；不会调用 OpenResty 发布、回滚或节点启停。

## 运行

先在集成工作区中运行 `./orp-backend/dev.sh`，启动本地 MySQL、Redis、Kafka、Go 控制面和 Vite。确认 `http://127.0.0.1:5666` 可以打开，然后执行：

```bash
cd orp-frontend
pnpm test:backend-ui
```

Playwright 会打开单独的 Chromium 窗口。登录页出现时，请手动拖动滑块并提交登录；测试等待登录后继续访问所有业务路由。不要关闭该测试窗口。

## 覆盖

脚本通过侧边栏和头像菜单逐页检查大盘、中心、节点、上游、HTTP、Stream、TLS、DNS、IP 组、配置下发、实时日志、审计、系统配置、个人中心、用户/角色/权限和接口文档，并记录每个页面实际收到的 `/api/` 响应。它会创建并保留一个无资源关联的中心：

- 标识码：`codex-ui-e2e`
- 名称：`自动化验收测试中心`
- 备注：`ORP UI backend smoke test data; safe to keep.`

如果该标识码已存在但备注不同，测试会停止，不会覆盖现有记录。重新运行时会确认这条测试数据仍可从 Go 后端读取。

## 结果

Playwright 列表和 HTML 报告输出到 `output/backend-ui-playwright/`；失败时附带 trace 和截图。此脚本覆盖真实页面读取及中心新增/重读，发布、回滚、节点状态变更以及 RBAC 权限写入不在自动流程中，避免改变 OpenResty 运行状态或用户权限。
